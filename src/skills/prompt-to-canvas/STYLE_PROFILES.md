# Style Comparison Profiles

Read alongside [CATALOG.md](CATALOG.md) when selecting candidates. These are concise summaries
of the linked design files, not new templates or fixed page layouts. The **family** labels are
maintainer groupings for comparing visual similarity, not upstream categories or hard bans.

**Density:** `open` = explicit air/minimal labels/hero treatment; `compact` = explicit tight,
abutting, or dense framing; `unspecified` = no supported density preference, not “fits every load”.
These describe visual rhythm, not a numeric capacity limit. Unknown depth/type details remain
unspecified; read the selected design before drawing. Each source link quotes an exact excerpt
for traceability. Apply the medium rules before any motif, decorative label, or font suggestion.
The converter supports native text families but not arbitrary SVG font weights; express
hierarchy through size, spacing, placement, and contrast. Never promise a reference typeface.

Compare actual dimensions, not just family names. Styles in one family can differ substantially;
styles in different families can still share a palette and rhythm. Fit takes precedence over variety.
Do not copy preview columns, stage counts, sample labels, or aspect ratio.
