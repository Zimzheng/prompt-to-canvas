# Prompt to Canvas 用户指南

在 Codex、Claude Code 等支持本地技能的 Agent 中，描述内容与用途即可：

> 用 prompt-to-canvas 画出订单异常处理流程，包括正常路径、重试和转人工。

未指定风格时，Agent 自主选择并直接生成。35 种风格是视觉参考，也允许协调的自定义风格。
可以指定品牌、风格名、参考图、画布比例或用途；同系列保持一致。若需要选项，可以要求
“先给我几个视觉方向”。需要多个成品时说明数量。

构图由关系决定，可组合泳道、决策分支、嵌套边界、反馈回路与局部展开。没有固定三栏布局
或全局节点数限制。信息不足以判断流程事实时，Agent 会询问，不会编造业务条件和指标。

## 编辑与导出

技能通过本地 HTTP 打开内置 Excalidraw 编辑器，支持中英文界面、PNG/SVG 导出和浏览器本地
自动保存。保留生成的 SVG 与 scene JSON；场景可继续编辑。分组支持联合选择，显式绑定的
节点标签及箭头端点可以随节点移动。复杂路线仍需在编辑后检查，当前没有自动避障布局。

每次新生成有独立本地链接；HTTP 服务结束后链接会失效。请保存文件和所需导出。
本地编辑器的场景加载与自动保存发生在本机；内容送入哪个模型取决于所使用的 Agent。

## 运行条件

普通使用需要 Node.js 20+，编辑器已经预构建，无需安装前端依赖。运行技能中的
`scripts/preflight.sh` 检查；Node 不在 PATH 时可使用现有运行时的绝对路径。不要直接用
file:// 打开编辑器，使用 `scripts/open-editor.mjs`。

开发编辑器时才需要在仓库运行 `npm ci` 和 `npm run build:skill`。

## 已知边界

SVG 支持明确的子集，详见 [能力说明](../src/skills/prompt-to-canvas/RULES.md)。曲线路径转换成
可编辑采样点，不保留 Bézier 控制柄；文本尺寸仍是估算，必须检查实际编辑器和导出。
不支持的可见特性会报错，避免悄悄丢失内容。当前没有内置 PDF 导出或多人协作。
